# Afaan Oromo Tourism Question Answering Chatbot

## Project Overview
The Afaan Oromo Tourism Question Answering Chatbot is an AI-powered system developed to provide tourism-related information in Afaan Oromo language. The chatbot uses semantic similarity and Sentence Transformers to understand user questions and retrieve the most relevant answers from a tourism knowledge base.

The system focuses on Ethiopian tourism destinations, while supporting Afaan Oromo language interaction.

---

## Features
- Afaan Oromo question answering system
- Semantic search using Sentence Transformers
- Tourism information retrieval
- GPU acceleration support with PyTorch
- Automated evaluation and accuracy testing
- Multilingual embedding model support
